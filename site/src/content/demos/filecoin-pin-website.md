Drop a file on the page and watch each step of pinning it: packing, upload to a storage provider, the on-chain commit and the indexing that makes it readable from IPFS gateways. It runs on the calibration testnet with a shared demo wallet, so there is nothing to set up, and the repository is made to be forked.
